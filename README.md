## About me

I work at the intersection of **agent systems, machine learning, and software engineering**. My background spans e-commerce, recommendations, computer vision, and production ML; today, I focus on the architectures and infrastructure behind LLM-powered applications.

At **Lensing AI**, I’m a core engineer within the **AISpecify Build/Compiler team**. I designed and built graph-based orchestration and AI observability, alongside compiler infrastructure, context engineering, and an extensible agent harness. My work connects architecture experiments to a larger production platform—not just isolated demos.

I’m especially interested in **agent execution policies, feedback loops, model adaptation, and evaluation**: what changes a system’s behavior, how to measure it, and which ideas hold up in practice.

The longer story—experience, research, education, and interactive walkthroughs—is on **[my portfolio](https://mohsenshahverdy.github.io/)**.
